Extensions

The simplest way to specify the response format is by appending a response type extension to the URL. This allows you to set the response format without requiring the ability to set headers in your HTTP client.

Simply add the extension to the endpoint. For example, if your resource endpoint is/resource/644b-gaut, and you wanted to get CSV output, your path would be/resource/644b-gaut.csv.

HTTP Acceptheaders allow applications to automatically negotiate content types with a web service. With SODA, this also means you can request content types using Accept headers without needing to provide a response type extension.

Simply send anAcceptheader along with the desiredmimetypefor the desired response type. For example, to requestJSON, you’d use a header ofAccept: application/json.

The SODA API response will also include aContent-typeheader to specify the format of the data that it is returning.
